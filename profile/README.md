# Mazhar Labs

We build and run websites and internal tools for fintech and service businesses, from the first design to production servers, monitoring and backups.

**What you get from us:** one team that designs the site, writes the code, sets up hosting and security, and keeps it running after launch.

## What we do

| | |
|---|---|
| **Websites on WordPress** | Custom themes, redesigns, multilingual sites (Polylang), SEO landing pages generated from live data, content managed from the admin panel without a developer. |
| **Performance** | Core Web Vitals and Lighthouse work: LCP, caching, image strategy, edge caching of HTML on Cloudflare. |
| **Infrastructure** | Docker on VPS, nginx, Cloudflare (WAF, rate limiting, Access, TLS), separate dev and production environments, releases with a one-command rollback. |
| **Reliability** | Daily off-site backups (Cloudflare R2, restic), health checks, Telegram alerts, structured logs and daily summaries. |
| **Security** | Secrets in 1Password instead of `.env` files, two-factor admin login, hidden login URL, CSP, HSTS, update policy. |
| **Customer support tools** | Self-hosted live chat (Chatwoot) and an AI assistant on the Claude API that answers from the site's own knowledge base. |
| **Integrations** | Exchange and payment platforms, KYC/AML verification flows, Notion and Telegram notifications, email delivery through Google Workspace. |
| **Internal dashboards** | Reporting and reconciliation tools for currency exchange offices. |
